# Graph Analysis

Program Java untuk menganalisis graf berarah berbobot menggunakan struktur data Adjacency List.

## Features
- Weighted Directed Graph
- Graph Visualization using Adjacency List
- Connected Components Analysis
- Cycle Detection using DFS (Three Color Method)
- Cycle Path Display

## Algorithms
- Depth First Search (DFS)
- Three Color Method

## How to Run

Compile:
javac GraphAnalysis.java

Run:
java GraphAnalysis

## Example Input

Jumlah simpul: 4
Jumlah sisi: 4

0 1 5
1 2 3
2 0 2
2 3 4

## Output
- Menampilkan graf
- Menghitung jumlah komponen terhubung
- Mendeteksi apakah terdapat siklus pada graf
- Menampilkan jalur siklus jika ditemukan
